## Agent skills

### Issue tracker

Issues are stored as local markdown files under `.scratch/<feature-slug>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default label mapping — the five canonical role names are used as-is. See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context layout — `app/` (frontend) and `svc/` (backend) each have their own context, with shared system-wide ADRs at the repo root `docs/adr/`. See `docs/agents/domain.md`.
